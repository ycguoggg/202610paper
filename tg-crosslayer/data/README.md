# Dataset Availability

The datasets associated with this project contain malicious or fraud-related Android applications and potentially sensitive infrastructure observations. To reduce the risks of misuse, the original samples and measurement data are **not included** in this public repository.

Relevant research data will be made available upon reasonable request, subject to appropriate safety and usage review. The dataset is under ongoing development and will be continuously expanded with additional related samples.

This directory contains documentation only. No malicious applications, real endpoints, private records, or experiment logs are distributed here.
